The website uses the resized photos in  photos/web/  (01.jpg ... 16.jpg).
Your full-size originals were moved to  Surprice Gift/original-photos/
so they don't get uploaded with the site.

To add a photo: resize it (~1200px tall, under ~300 KB), put it in photos/web/,
then add an entry in src/config/photos.js with  src: '/photos/web/your-file.jpg'
